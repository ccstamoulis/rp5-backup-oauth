Privacy Policy

Effective November 24, 2026.

Purpose

RP5 Backup Manager is a personal backup and restoration utility for use by its operator.

Google Drive access

The application accesses Google Drive through Rclone and OAuth to list, create, upload, download and manage backup repository files.

Data storage and protection

Backup contents are intended to be encrypted locally using Restic before transfer to the operator's Google Drive account. OAuth credentials are stored locally by Rclone.

Data sharing

The application does not sell user data, use it for advertising, or intentionally disclose backup contents to unrelated third parties. Google provides storage and authentication services. GitHub hosts this informational website.

Retention and deletion

The operator controls backup retention and may delete backup data or revoke OAuth access through Google Account settings.

Google API compliance

Use of information received from Google APIs is subject to the Google API Services User Data Policy, including Limited Use requirements.
